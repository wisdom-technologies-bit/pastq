# Bank questions response shape

The v1 contract was validated against the session questions endpoint. The envelope is `{ data, meta }`; each item uses `ref`, 1-based `number`, `subject`, `passage` (object or null; passage HTML is in its `text`/`html` fields), `question: { text, image_url? }`, `options: [{ key, text }]`, and optional `your_choice` and `flagged`. Review responses add `correct_choice` and `is_correct`. PastQ treats the envelope and nested records as passthrough/lenient because the Bank may add fields. Only `https://` image URLs are forwarded. The player now records and handles the Bank's figure fields defensively: `question.image_url` is the preferred source, while `<img>` sources in question/option HTML are extracted client-side only after the API sanitizer removes unsafe markup. The current verified response contract did not include a separate `image` field; relative or non-HTTPS image sources are not forwarded until their Bank host is explicitly allowlisted.
